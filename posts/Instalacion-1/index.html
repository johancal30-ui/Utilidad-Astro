Instalación de Astro en Linux

Antes de comenzar con el desarrollo del sitio web estático, es necesario preparar el entorno de trabajo. A continuación se detallan los requisitos previos y los pasos de instalación.

Requisitos previos

  • Node.js versión 18 o superior
  • npm (gestor de paquetes de Node.js)
  • Git para control de versiones
  • Editor de código (Visual Studio Code recomendado)

Verificar instalación de Node.js y npm

node -v
npm -v
