# Tailwind CSS en Astro

## ¿Qué es Tailwind?
Tailwind es un framework de CSS que permite aplicar estilos directamente en las clases de tus etiquetas HTML, haciendo que el diseño sea más rápido y sencillo.

## Instalación
Para agregar Tailwind a tu proyecto Astro, abre la terminal y escribe:


```bash
npm install -D tailwindcss
```
