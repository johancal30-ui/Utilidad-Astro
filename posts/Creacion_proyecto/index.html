Creación del Proyecto Astro

Una vez que tenemos instalados los requisitos previos (Node.js, npm y Git), podemos proceder a crear nuestro proyecto Astro. Este proceso se realiza desde la terminal y nos permitirá configurar la estructura inicial de nuestro sitio web estático.

Paso 1: Inicializar el proyecto

En la terminal, ejecuta el siguiente comando:

npm create astro@latest
