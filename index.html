Bienvenido al Manual Técnico desarrollado como evidencia de aprendizaje para la construcción de un sitio web estático multipágina. Este proyecto tiene como finalidad documentar el proceso de instalación, configuración y desarrollo de una aplicación web utilizando Astro, Tailwind CSS y CSS tradicional en un entorno Linux. A través de este manual se presentan los conceptos fundamentales empleados durante el desarrollo del proyecto, siguiendo buenas prácticas de organización, reutilización de código y diseño responsivo.
